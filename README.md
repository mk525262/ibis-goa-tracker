# ibis Goa Calangute Price Tracker

Independent price tracker for **ibis Styles Goa Calangute**.

Target stay: 28 Nov 2026 to 2 Dec 2026 (4 nights), 2 guests.
Target room/rate: Standard Twin Room – Pool View, Flexible Rate – Half Board.
Baseline total: ₹37,605.75.

This repository is intentionally separate from any other hotel tracker.

## Telegram
The tracker sends alerts through the dedicated `@Goa_IBIS_bot` Telegram bot.

Required GitHub Actions secrets:
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

Never commit either secret to the repository.
